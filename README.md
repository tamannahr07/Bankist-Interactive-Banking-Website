# Bankist – Interactive Banking Website

A modern and interactive banking landing page built with **HTML5, CSS3, and Vanilla JavaScript**. The project focuses on creating a clean digital banking experience while demonstrating practical frontend development techniques, DOM manipulation, browser APIs, animations, and interactive UI components.

## Overview

Bankist is a frontend banking website designed with a modern and minimalist interface. It includes multiple interactive components that make the website feel more dynamic and engaging rather than functioning as a static landing page.

The project was built to strengthen practical understanding of **JavaScript, DOM manipulation, browser APIs, UI interactions, and performance-oriented frontend techniques**.

## Features

* Responsive and modern banking landing page
* Smooth scrolling navigation
* Interactive navigation menu
* Sticky navigation using the **Intersection Observer API**
* Section reveal animations while scrolling
* Lazy loading of images
* Image loading blur effect
* Interactive banking operations tabs
* Account opening modal window
* Modal overlay and keyboard interaction
* Testimonial/image slider
* Previous and next slide controls
* Dynamic slider navigation dots
* Keyboard navigation for the slider
* Cookie consent message
* SVG-based icons
* CSS transitions and animations

## Technologies Used

## Key JavaScript Concepts

This project demonstrates practical implementation of several JavaScript concepts:

### DOM Manipulation

The interface is dynamically controlled using JavaScript to update elements, classes, attributes, and content based on user interaction.

### Event Handling

The project uses event listeners for navigation, tabs, modal controls, slider controls, keyboard interaction, and other UI components.

### Intersection Observer API

The Intersection Observer API is used to detect when elements enter the viewport. This enables:

* Section reveal animations
* Lazy loading of images
* Sticky navigation behaviour

### Interactive Slider

The testimonial section includes a JavaScript-powered slider with:

* Previous/next controls
* Dynamic navigation dots
* Keyboard navigation
* Programmatic slide movement

### Lazy Loading

Images are loaded when they approach the viewport instead of loading everything immediately, helping improve initial page loading behaviour.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Bankist-Website.git
```

### 2. Navigate to the project

```bash
cd Bankist-Website
```

### 3. Run the project

Open `index.html` directly in your browser, or use a local development server such as **VS Code Live Server**.

No backend server or database is required.
